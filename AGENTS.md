# AGENTS.md — Repository Skill Memory

## Project Purpose
Quantitative finance research: K-means market state classification + Bayesian Markov
dynamic portfolio blending. Covers 4 experiments (exp_1–exp_4).

## Repository Layout
- `src/` — core modules (data_loader, market_states, portfolio_static, markov_transition,
  dynamic_portfolio, visualization)
- `exp/` — one runner per experiment + `run_all.py` orchestrator
- `tests/` — 115 pytest tests (test_exp1–test_exp4)
- `data/` — CSV exports; parquet/pickle files are .gitignored (regenerated by pipeline)
- `results/` — RESULTS.md + all 8 PNGs + annual/full-period CSV tables

## Key Implementation Decisions

### Data Loading (`src/data_loader.py`)
- `yfinance` with `auto_adjust=True` for `Adj Close`; BTC-USD gets `Close`
- Inner-join (dropna(how='any')) across all assets to align to equity trading days
- 30-calendar-day download buffer before analysis start to fill 22-day rolling window

### Market States (`src/market_states.py`)
- `KMeans(n_clusters=10, n_init=50, max_iter=1000, random_state=42)`
- State ordering: argsort of centroids → mapping {old_label: 1..10}
- Validation: states 1-3 > 50% for Asset Set 1; Asset Set 2 (BTC) check is a warning
  (not hard raise) because BTC raises baseline volatility

### Portfolio Static (`src/portfolio_static.py`)
- Uses `scipy.optimize.minimize(method='SLSQP')` with long-only, sum=1 constraints
- Covariance regularised: `Sigma + 1e-8 * I` if near-singular
- ERC objective: `sum((TRC_i - mean(TRC))^2)` with `ftol=1e-12`, `maxiter=1000`
- Library: checked via Context7; custom SLSQP used (skfolio confirmed but scipy chosen
  to avoid heavy dependency for this specific formulation)

### Markov Transition (`src/markov_transition.py`)
- Transition counts N[i,j] from consecutive state pairs (0-indexed)
- Posterior mean: `(1 + N[i,j]) / (10 + sum_k N[i,k])`
- Gibbs sampling: 4 chains × 10,000 iter, burn-in 2,000; conjugate Dirichlet → i.i.d. samples
- R-hat via `arviz.rhat`; max R-hat should be << 1.1
- Eigenvalue SLEM: `np.linalg.eigvals(P_mean)`; sort abs descending; idx 1

### Dynamic Portfolio (`src/dynamic_portfolio.py`)
- Binary assignment: best strategy per state by cumulative compound return on state days
- Total return weights: `W = P_mean @ p_m` for each strategy m
- Daily return: `r_dyn[t+1] = W[state_t-1, :] · [r_EW, r_MinVar, r_MaxDiv, r_ERC][t+1]`
- **Custom Sharpe = compound_return / std(daily_returns, ddof=1)** — NOT annualised

## Known Quirks / Gotchas
1. **BTC-USD is 365-day but inner-join restricts to equity trading days** — handled automatically
2. **Asset Set 2 low-vol-states check** — BTC's high baseline causes states 1-3 < 60%; validation prints warning instead of raising
3. **LIN backdated** — yfinance provides full history; accepted as-is per methodology
4. **Custom Sharpe is non-standard** — confirmed paper definition: compound_return / daily_std
5. **Data files** — parquet/pkl in `.gitignore`; CSV exports (returns, states, matrices) are committed
